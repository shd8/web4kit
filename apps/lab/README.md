# web4 lab

A local developer tool for working on web4 itself: live engines (rules, a local System One endpoint, Jev, the cascade), an engine switcher, arbitrary context controls and the Why panel, over the restaurant and the database explorer.

```bash
W4_LAB_MODE=1 pnpm dev   # http://localhost:3004
```

The lab is not deployed. The public demo is the static playground of the site (`apps/site`), which serves precomputed plans with no engine at runtime.
